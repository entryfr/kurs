## Что реализовано сейчас

1. **Новая архитектура с нуля**
   - Отдельный модуль `src/ai_agent_course`.
   - Новый web/API вход: **картинка + текстовый запрос**.

2. **Цепочка задач по ТЗ (базовая рабочая версия)**
   - Шаг 1: аффинная трансформация (LSQ).
   - Шаг 2: Canny + Hough, фильтр линейных аномалий `>10м`, буфер 2.5м, blind-zones.
   - Шаг 3: классификация типа коммуникации (RandomForest, 14 признаков).
   - Шаг 4: риск 89/62/12 + индекс `R = P(comm) × P(damage|depth) × W`.
   - Шаг 5: расчёт `T_ост` и предупреждение при `T_ост < 5`.
   - Шаг 6: генерация `DXF`, `MIIS XML`, `PDF`.

3. **Нормативный контроль**
   - Проверки `R01..R12` в модуле `validation.py`.
   - Сводка нарушений `issues_by_rule`.

4. **Тесты**
   - `tests/test_agent_v2_web.py` (UI/API smoke + contract).
